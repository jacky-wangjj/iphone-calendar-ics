3离线包：不订阅也能用

A 方案的第一条路。不需要服务器、不需要联网，拿到文件就能导入；代价是明年要重新导入一次。

日历增强包 · 离线版

一个网页 · 6 个 .ics 打包在内 · 覆盖 2026–2027 · 可微信直接转发

日历数据已经打包进这一个网页里：calendar.ics（主层 121 条）、yiji.ics（宜忌 730 条）和四个单年版。打开后点按钮就能保存，转发时只发这一个网页即可，不依赖其他文件。一般只用主层这一个。

打开离线包（保存 .ics + 图文说明）
离线包可以直接发给别人。对方用手机或电脑打开这个网页，点里面的按钮就能把 .ics 存下来，不需要联网找文件。
导入 ≠ 订阅。导入是把这份数据复制进日历，之后不会自动更新；订阅是给日历一个网址，让它自己定期去拉，一次配置长期有效。两者数据一样，但不要同时用，否则同一天会有两条重复事件。

5其他设备

Mac

日历 App → 文件 → 新增日历订阅 → 粘贴地址 → 自动刷新选「每天」

用同一个 iCloud 账户时，Mac 上订的日历会自动出现在 iPhone 上，不必重复操作。

Android

不同品牌入口不一样，通用路径是「日历 App → 设置 → 添加日历 → URL 导入」

小米日历 → 设置 → 日程导入 → URL 导入
华为 / 荣耀日历 → 设置 → 订阅管理 → 添加订阅
原生 AndroidGoogle 日历网页版 → 其他日历 → 通过网址添加
其他先「下载 .ics 文件」，再用日历 App 打开导入
Android 上「订阅」和「导入」是两件事：订阅会持续同步，导入只是一次性拷贝、之后不再更新。能用订阅就别用导入。

6退订、换源与年更

退订

iPhone：日历 App → 底部「日历」按钮 → 找到这个订阅 → 点 ⓘ → 删除日历。也可以走「设置 → 日历 → 账户 → 已订阅的日历 → 删除账户」。

退订宜忌层不影响主层 —— 两层是完全独立的两个日历账户。

会不会每年都要重订一次

不用。这是订阅日历，不是下载的文件

每年 11 月国务院发布次年安排后，服务端会覆盖同一个地址里的内容，你的手机下次刷新时自动拿到新数据，接口地址一个字都不变。

你怎么知道已经更新了？看日历名字 —— 它会从「中国节假日与节气 2026–2027」变成「中国节假日与节气 2027–2028」。名字里的年份就是更新信号。

7常见问题

现象原因与处理
打开链接是一屏乱码这个地址的 MIME 不是 text/calendar。典型是 raw.githubusercontent.com，换成 jsDelivr 地址即可。
订上了但日历空白① 日历 App 底部「日历」里没勾选这个订阅；② 客户端还没刷新，下拉一次或等一小时。
同一天出现两条一样的事件同时订了「合订版」和「单年版」。删掉单年版，留合订版。
标题显示不全，后面是省略号月视图宽度有限，横屏或切到列表视图即可看全。本产品标题最长 11 字，列表视图一定能完整显示。
年更后 iPhone 上还是旧数据客户端默认可能一周才拉一次。下拉刷新，或到「设置 → 日历 → 账户 → 获取新数据」改成「推送 + 每 15 分钟」。
能不能只订宜忌，不要节假日可以。两层是独立地址，只订 yiji.ics 就行。
要占多少空间主层 24 KB、宜忌层 163 KB，两次微信图片的量级。订阅日历不存本地图片，也不常驻后台。
离线包导入后能自动更新吗不能。导入是一次性复制，明年要重新导入一次。想年更自动生效，用第 4 节的订阅链接；两者不要同时用。
数据口径：法定节假日依据国务院办公厅年度通知，逐年人工录入，绝不推算；黄历依据《钦定协纪辨方书》底本推算，属民俗参考。
